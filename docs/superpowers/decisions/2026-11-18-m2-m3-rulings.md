# M2+M3 — rulings and deferred items

These are the decisions the build controller made on the owner's behalf while executing the M2+M3 plan (`docs/superpowers/plans/2026-11-17-tide-m2-m3-library-reader.md`). Each one is written as: what was decided — why — what it costs if wrong. After them come the minor review findings deferred to later milestones, and the checks left for the owner. Exported from the execution ledger on 2026-11-18, after the final whole-branch review came back clean. Branch `feat/m2-m3-library-reader`, 544a97a..873c581. Reading content appears nowhere; local-reading checks are aggregate numbers only.

## Rulings (in the order made)

1. Work on the feature branch in place, not in a git worktree. The native worktree tool targets the D:\ root repo, and a separate worktree would hide the git-ignored local-fixtures/ and resources/models — cost if wrong: none (single-branch work).
1. The preflight scan of the 938-line plan was delegated to a Sonnet reader, and the controller ruled on every row it flagged — cost if wrong: a missed conflict surfaces in task review instead.
1. All 15 preflight findings were resolved in per-task plan amendments, carried into each dispatch, so plan defects were fixed at the source — cost if wrong: a task follows an amendment its reviewer disagrees with, and the reviewer flags it.
1. `PIPELINE_VERSION` was bumped once to 3 for the whole branch, because nothing has cached or released v3 output — cost if wrong: none until a text cache exists.
1. Vite `assetsInlineLimit: 0` for the renderer, instead of loosening CSP `font-src`, keeps the CSP exactly as specified — cost if wrong: a few more tiny asset files.
1. Three Task 1 minors were fixed early: the stage remounted across the 1100 px breakpoint (which would have broken reader state), the overlay `open` went stale, and fonts are now latin-only subsets for installer size — cost if wrong: one small extra round.
1. Two Task 2 minors were fixed early. The backup copy is best-effort, so an AV-locked backup can't block the primary write. A failed write is retried, and `flush()` returns `Promise<boolean>`. "Never lose the shelf" is the spec's core promise — cost if wrong: one small round.
1. Commit trailers name the model that actually wrote the commit, not a fixed Opus line, for honest attribution — cost if wrong: cosmetic trailer differences.
1. The raw hex in Task 1's Wordmark was folded into the Task 6 fix (same tokens-only constraint) — cost if wrong: none.
1. New logo tokens `--logo-sun`, `--logo-wave-a` and `--logo-wave-b` were accepted. The Deep Sea logo values are provisional and get design sign-off in M6 — cost if wrong: a logo tint tweak in M6.
1. The default window is 1200×800 content size (`useContentSize`), because 1100 outer px on Windows gave ~1086 px of content, under the breakpoint, so the shelf was hidden on first launch. The minimum stays 900×600 — cost if wrong: the window is slightly larger on first launch (it fits a 13" MacBook Air).
1. Task 8 minors were folded into its first fix round: the single-slot pick queue dropped multi-select Open With files, Open With failures were silent, constant names, a weak e2e, and the renderer state when Library.open fails. Multi-select "Open with Tide" is her normal path — cost if wrong: a slightly larger round.
1. Task 9 minors 1–4 were fixed early: a missing-row click left an empty header, a dead clear-selection after Remove, Remove double-click, and test gaps. All are visible on a first try — cost if wrong: one small round.
1. The footnote-start floor is ≥ 2 words containing letters (not the plan's 3), and the single-column fixture edit was reverted. The rule exists to exclude axis labels (0 lettered words), and 3 would speak short citation footnotes ("See Author (year).") — cost if wrong: a 2-word lettered small line at the page bottom (e.g. "Source: Author") is dropped as a footnote.
1. A chart's axis-label line is still spoken. This is existing behaviour and outside Task 11's rules — cost if wrong: a stray run of numbers is read aloud on chart pages. It is a candidate for a later text-quality pass.
1. The initials exception does not apply when the next segment is itself a single capital plus a full stop ("Smith, J. A. found it." stays one sentence). The intent was that initials stop swallowing sentence ends, not that names with several initials get split — cost if wrong: none (the exception is narrower).
1. `filtersFor(settings, readEverything)` lives in `src/renderer/src/reader/filters.ts`, following the amendment rather than the brief's `(r, s)` form — cost if wrong: a trivial call-site change.
1. Task 14's manual check became a Playwright smoke (two-column/layout render, locked.pdf with password `tide`, zoom) plus the owner checklist below. The open-to-sentences timing was measured as a node run over the local readings (numbers only) — cost if wrong: the timing leaves out worker overhead; the Task 16 e2e covers the real path.
