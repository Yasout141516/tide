Shelf, Add reading, shelf rows and Settings show the default ring (`outline-style: auto`). Cause: `PlayerBar.tsx`, `VoicePopover.tsx`, `SleepPopover.tsx` use `outline-none focus-visible:outline-2 ...`; in Tailwind 4 `outline-none` sets `--tw-outline-style: none` and `focus-visible:outline-2` draws with `outline-style: var(--tw-outline-style)`, so no ring is drawn.
